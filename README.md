# 📊 Global Data Jobs Market Analysis (2023)

## 📌 Project Overview

This project analyzes the **2023 Global Data Jobs Market** using **PostgreSQL**. The goal is to uncover hiring trends, salary patterns, remote work opportunities, and the most in-demand technical skills by answering real business questions through SQL.

The project demonstrates practical SQL skills such as data profiling, data cleaning, aggregation, Common Table Expressions (CTEs), subqueries, string manipulation, and exploratory data analysis.

---

## 📂 Dataset

- **Source:** Luke Barousse – Data Jobs Dataset
- **Year:** 2023
- **Database:** PostgreSQL
- **Total Records:** ~786,000 job postings

---

## 🎯 Business Questions

This project answers the following business questions:

1. Which job roles had the highest hiring demand?
2. Which countries had the highest demand for data professionals?
3. What is the distribution of remote and on-site jobs?
4. Which job roles offered the highest percentage of remote work opportunities?
5. Which job roles had the highest average annual salaries?
6. Which countries offered the highest average salaries for Data Analysts?
7. Which technical skills were most frequently required across data-related job postings?
8. Which high-demand technical skills offered the highest average annual salaries?

## 📈 Key Findings

- Data Analyst, Data Engineer, and Data Scientist accounted for nearly **70%** of all job postings.
- The **United States** had the highest hiring demand for data professionals.
- Approximately **91%** of job postings were on-site, while remote opportunities were more common in senior-level roles.
- Senior Data Scientists earned the highest average annual salaries among major job roles.
- SQL and Python were the most in-demand technical skills.
- Cloud, big data, and machine learning technologies offered the strongest combination of market demand and competitive salaries.
